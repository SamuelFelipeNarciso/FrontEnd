Tutorial: Termo (Wordle)

Este guia prático ensinará os fundamentos do React construindo uma versão real do jogo Termo.

Neste tutorial, construiremos um clone interativo do famoso jogo de adivinhação de palavras. Através deste projeto, você verá na prática como planejar componentes organizados, gerenciar estados de matrizes e capturar inputs globais de periféricos.

O que você vai aprender:

Você vai entender a fundo o conceito de Elevação de Estado (Lifting State Up) e como o Hook useEffect sincroniza sua aplicação com eventos nativos do navegador.

1. Construindo a Interface (UI)

A interface do Termo é essencialmente uma matriz estrutural. Diferente de elementos dinâmicos isolados, o tabuleiro necessita de uma hierarquia rígida dividida em três níveis:

Diagrama 1: Fluxo de Dados Unidirecional no React
Game.jsx (Estado Central)
▼ props (guesses)
Board.jsx (Gerenciador da Grade)
▼ props (guess string)
Row.jsx (Computador da Linha)
▼ props (char / status)
Tile.jsx (Elemento Atômico)
  • Tile: O bloco atômico visual que renderiza um único caractere por vez.
  • Row: O agrupamento horizontal rígido de exatamente 5 Tiles.
  • Board: A matriz vertical completa composta por 6 Rows estruturais.

Criando o Componente Tile

O componente Tile é uma função pura que aceita duas propriedades do seu componente pai: a letra (letter) e a cor de verificação (status).

function Tile({ letter, status }) {
  let tileClass = "tile";
  
  if (status === "correct") tileClass += " correct";
  if (status === "present") tileClass += " present";
  if (status === "absent") tileClass += " absent";
  if (letter && !status) tileClass += " active";

  return <div className={tileClass}>{letter}</div>;
}

2. Elevando o Estado (Lifting State Up)

No React, o fluxo de dados acontece de cima para baixo. Se deixarmos que cada linha (Row) controle seus próprios caracteres de forma isolada, o componente centralizador não conseguirá computar se o jogador atingiu o limite de tentativas.

Diagrama 3: Divisão Estrutural da Matriz de Tentativas
guesses[0] (Histórico)
currentGuess (Ativa)
Linha Vazia 3
Linha Vazia 4
Linha Vazia 5
Linha Vazia 6

Para resolver isso, nós elevamos o estado para o componente pai mais próximo (Game). Ele controlará o histórico através de dois estados essenciais:

const [guesses, setGuesses] = useState([]);        // Array de strings submetidas
const [currentGuess, setCurrentGuess] = useState(""); // Palavra sendo digitada na linha ativa

3. Capturando Eventos Globais

Para permitir que o jogador digite usando qualquer tecla do teclado físico, precisamos acoplar um escutador de eventos global na janela (window). Executamos isso mapeando o ciclo de vida por meio do Hook useEffect:

useEffect(() => {
  function handleKeyDown(event) {
    const key = event.key.toUpperCase();

    if (key === "ENTER") {
      if (currentGuess.length === 5) {
        setGuesses([...guesses, currentGuess]);
        setCurrentGuess("");
      }
      return;
    }

    if (key === "BACKSPACE") {
      setCurrentGuess((prev) => prev.slice(0, -1));
      return;
    }

    if (/^[A-Z]$/.test(key) && currentGuess.length < 5) {
      setCurrentGuess((prev) => prev + key);
    }
  }

  window.addEventListener("keydown", handleKeyDown);
  return () => window.removeEventListener("keydown", handleKeyDown);
}, [currentGuess, guesses]);

4. O Algoritmo de Validação das Cores

Deep Dive: Evitando o Bug de Letras Duplicadas

Se a palavra certa for TERMO (apenas um 'E') e o usuário chutar FEVRE, apenas o primeiro 'E' deve pintar de amarelo. O segundo deve ficar cinza. Usamos um algoritmo de duas passadas para resolver isso de forma precisa.

Abaixo está a lógica da segunda passada estruturada dentro do componente Row:

// Passada 1: Marca os acertos exatos (Verdes)
for (let i = 0; i < 5; i++) {
  if (guess[i] === solution[i]) {
    statuses[i] = "correct";
    solutionLetters[i] = null;
  }
}

// Passada 2: Marca letters deslocadas (Amarelos)
for (let i = 0; i < 5; i++) {
  if (statuses[i] === "") {
    const indexInSolution = solutionLetters.indexOf(guess[i]);
    if (indexInSolution !== -1) {
      statuses[i] = "present";
      solutionLetters[indexInSolution] = null;
    } else {
      statuses[i] = "absent";
    }
  }
}

5. Estilizando com CSS Reativo

No React, a renderização visual é inteiramente orientada por dados. À medida que o estado muda no arquivo JavaScript, o HTML recebe novas classes associadas que disparam transições e cores específicas no arquivo CSS externo.

Diagrama 5: Junção entre String de Estado e Seletor CSS
.tile + .correct → Fundo Verde
